# Стратегия защиты данных «Медикаменте» с учётом состояния данных, чувствительности и профиля риска

## 1. Классификация данных

### 1.1. По уровню конфиденциальности

| Класс          | Описание           | Примеры                          |
|----------------|--------------------|----------------------------------|
| `public`       | Открытые данные    | Прайс услуг, адреса клиник       |
| `internal`     | Внутренние, не ПДн | Расписание, номенклатура ТМЦ     |
| `confidential` | ПДн, финансы       | ФИО, контакты, договоры, платежи |
| `sensitive`    | Спец. категория    | Диагнозы, анализы, заключения    |
| `secret`       | Секреты систем     | Ключи, токены, пароли            |

### 1.2. По состоянию и профилю риска

| Данные                        | Состояние                       | Чувствительность    | Профиль риска                |
|-------------------------------|---------------------------------|---------------------|------------------------------|
| ФИО, дата рождения            | at rest / in transit            | Высокая (ПДн)       | Идентификация субъекта       |
| Контакты (телефон, e-mail)    | at rest / in transit            | Высокая (ПДн)       | Спам, фишинг, деанонимизация |
| Адрес, место работы/учёбы     | at rest                         | Высокая (ПДн)       | Профилирование               |
| Медданные (диагнозы, анализы) | at rest / in transit            | Критическая (спец.) | Дискриминация, репутация     |
| Платежи, договоры, чеки       | at rest / in transit            | Высокая (фин.)      | Мошенничество                |
| Кадры, зарплаты               | at rest                         | Высокая (HR)        | Утечка ЗП, налоги            |
| Ключи, токены, пароли         | at rest / in transit / in use   | Критическая         | Компрометация всей системы   |
| Аналитические витрины         | at rest                         | Средняя (обезлич.)  | Реидентификация              |

## 2. Обоснование необходимости защиты выделенных классов и инструменты защиты данных

| 1. Данные                                     | 2. В чём необходимость защиты                                         | 3. Инструменты защиты                                                                                                                 |
|-----------------------------------------------|-----------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
| **ФИО, дата рождения**                        | ПДн по 152-ФЗ; идентификация субъекта; репутационные/штрафные риски   | At rest: TDE/AES-256 (PostgreSQL, диск); In transit: TLS 1.2+; RBAC/ABAC; аудит доступа; обезличивание для аналитики                  |
| **Контакты (телефон, e-mail)**                | ПДн; риск фишинга/спама и деанонимизации                              | Шифрование БД; TLS; маскирование в UI/логах; DLP                                                                                      |
| **Адрес, место работы/учёбы**                 | Расширенные ПДн; профилирование субъекта                              | Шифрование at rest; ABAC (доступ по необходимости); минимизация сбора                                                                 |
| **Медданные (диагнозы, анализы, заключения)** | Специальная категория ПДн; максимальный ущерб при утечке              | Усиленное шифрование (колоночное/AES-256) + KMS/HSM; mTLS между сервисами; строгий RBAC/ABAC; аудит чтения; обезличивание в Data Lake |
| **Платежи, договоры, чеки**                   | Финансовые данные; риск мошенничества, требования ФЗ                  | Шифрование at rest; TLS/mTLS; маскирование номеров карт; токенизация; аудит                                                           |
| **Кадры, зарплаты (HR)**                      | Персональные + финансовые данные сотрудников                          | Шифрование БД 1С/хранилища; RBAC; сегментация доступа бухгалтерии                                                                     |
| **Ключи, токены, пароли**                     | Компрометация ведёт к доступу ко всем данным                          | KMS / HashiCorp Vault; ротация ключей; хранение секретов вне кода; HSM                                                                |
| **Резервные копии**                           | Содержат все категории; частая цель атак                              | Шифрование бэкапов; off-site хранение; контроль целостности                                                                           |
| **Аналитические данные**                      | Риск реидентификации обезличенных данных                              | Псевдонимизация, k-анонимность, шифрование хранилища, разграничение доступа                                                           |

## 3. Инструменты защиты

### 3.1. Data at rest (в покое)
- **TDE / AES-256** для PostgreSQL и объектного хранилища (S3-совместимого).
- **Колоночное/полевое шифрование** для спец. категории (медданные).
- **KMS / HashiCorp Vault** - управление ключами, ротация; при необходимости **HSM**.
- **LUKS / dm-crypt** для шифрования дисков на уровне ОС.
- Шифрование резервных копий.

### 3.2. Data in transit (в передаче)
- **TLS 1.2+/1.3** для всех внешних соединений; **mTLS** между микросервисами.
- **API Gateway** с терминацией TLS, WAF.
- **VPN / IPsec** для связи филиалов, сегментация сети.

### 3.3. Автоматизированный контроль
- **DLP** (Data Loss Prevention) - контроль исходящих потоков, блокировка утечек.
- **SIEM** (Elastic/OpenSearch, Wazuh) - сбор и корреляция событий, алертинг аномалий.
- **Каталог данных** (OpenMetadata/DataHub/Apache Atlas) - классификация, теги, Data Lineage.
- **CI/CD security-гейты** - проверка релизов на работу с тегированными данными, SAST/секрет-сканеры.
- **IAM** - централизованный RBAC/ABAC, MFA, аудит выдачи доступов.
- **Мониторинг** - Victoria Metrics/Grafana для метрик, алерты по нетипичному доступу.

| Средство                                     | Тип           | Назначение                      | Состояние данных    |
|----------------------------------------------|---------------|---------------------------------|---------------------|
| HashiCorp Vault / KMS                        | ПО            | Управление ключами и секретами  | at rest, in use     |
| HSM (аппаратный модуль)                      | Аппаратное    | Хранение мастер-ключей          | at rest             |
| PostgreSQL TDE / pgcrypto                    | ПО            | Шифрование БД                   | at rest             |
| MinIO/S3 SSE                                 | ПО            | Шифрование объектного хранилища | at rest             |
| LUKS/dm-crypt                                | ПО            | Шифрование дисков               | at rest             |
| TLS/mTLS (nginx, Envoy)                      | ПО            | Шифрование каналов              | in transit          |
| API Gateway + WAF                            | ПО            | Защита периметра, TLS           | in transit          |
| DLP-система                                  | ПО            | Контроль утечек                 | in transit, at rest |
| SIEM (Elastic/Wazuh)                         | ПО            | Аудит, корреляция, алертинг     | все                 |
| Каталог данных (OpenMetadata/Atlas)          | ПО            | Классификация, теги, Lineage    | все                 |
| IAM/IdP (Keycloak)                           | ПО            | AuthN/AuthZ, MFA, RBAC/ABAC     | in use              |
| Межсетевой экран (NGFW)                      | Аппаратное/ПО | Сегментация сети                | in transit          |
| Аппаратный шлюз VPN                          | Аппаратное    | Защита связи филиалов           | in transit          |
| Средства резервного копирования (Veeam/borg) | ПО            | Шифрованные бэкапы              | at rest             |
